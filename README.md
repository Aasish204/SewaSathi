# SewaSathi - Intelligent Handyman Recommendation System

## Overview

SewaSathi is a handyman recommendation system developed as a final year project. 
The system helps customers find suitable handymen based on service requirements, location, ratings, experience, and completed jobs.

The system also includes an AI-based image classification module that helps identify possible repair issues from uploaded images.

---

## Features

- User authentication and profile management
- Handyman registration and service management
- Location-based handyman recommendation
- Weighted Scoring Model (WSM) for ranking handymen
- Booking and job management
- Real-time communication using WebSocket
- AI-based issue detection from images
- Location processing using geocoding and routing services
